# نظرات و نظرسنجی

- صفحهٔ عمومی از منوی «نظرات و نظرسنجی» باز می‌شود. برای ثبت بازخورد و رأی‌دادن، ورود با حساب موجود لازم است.
- بازخوردها با وضعیت «در انتظار بررسی» ثبت می‌شوند. از بخش مدیریتی می‌توان وضعیت را به «منتشرشده» یا «پنهان» تغییر داد، دسته را اصلاح کرد یا بازخورد را حذف کرد.
- برای انتشار نظرسنجی، دست‌کم دو گزینه بسازید و وضعیت را «باز» کنید. هر حساب یک بار رأی می‌دهد. نتیجه پس از رأی‌دادن، یا پس از بستن نظرسنجی برای همه، نمایش داده می‌شود.
