# اطلاعیه‌ها

- مدیر کل از بخش «کاربران و دسترسی‌ها» می‌تواند مجوزهای مشاهده، افزودن، ویرایش و حذف اطلاعیه را به کاربر دارای دسترسی کارمندی یا به گروه او بدهد. بارگذاری تصویر بخشی از فرم اطلاعیه است و مجوز جداگانه نمی‌خواهد.
- برای انتشار، گزینهٔ «منتشرشده» و زمان انتشار را تنظیم کنید. تا پیش از زمان انتشار، اطلاعیه و تصاویرش برای عموم نمایش داده نمی‌شوند.
- «برنامهٔ مرتبط هیئت» اختیاری است. برای اتصال به خوابگاه، واحد یا زیرواحد، از «واحدهای مرتبط» استفاده کنید.
- مسیر `MEDIA_ROOT/announcements/` را مستقیماً از وب‌سرور یا CDN ارائه نکنید؛ تصاویر از مسیر کنترل‌شدهٔ اپ ارائه می‌شوند.
