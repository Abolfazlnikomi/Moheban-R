# مدیریت واحدها

در پنل مدیریت، ابتدا «نوع واحد» و سپس واحدها را در «مدیریت واحدها» بسازید. والد اختیاری است. برای تفکیک خواهران و برادران می‌توانید زیرواحدهای جدا بسازید. غیرفعال‌کردن والد، شاخهٔ آن را از فیلتر عمومی و از گزینه‌های جدیدِ اتصال محتوا پنهان می‌کند و ارتباط‌های قبلی را حذف نمی‌کند.

اطلاعیه‌ها، نشریات، گزارش‌ها و پیوست‌های آن‌ها و پویش‌ها از همین ساختار استفاده می‌کنند. گزینهٔ «محتوای عمومی» امکان انتشار بدون واحد و حضور در فیلتر «فقط محتوای عمومی» را می‌دهد. محتوای واحدی که منتشر شده همچنان برای بازدیدکننده قابل مشاهده است؛ واحد و تفکیک جنسیتی مجوز دسترسی نیستند.

فیلتر `?unit=<id>` قابل اشتراک است و واحد فعال و زیرشاخه‌های فعال آن را پوشش می‌دهد. `?unit=public` فقط محتوای عمومی را نشان می‌دهد. برای افزودن نوع محتوایی جدید، از `UnitContent`، فرم مدیریتی مشترک و `unit_filter(request)` استفاده کنید.
